# Publication policy

Nothing in `publications/published/` merges without:

1. evidence id
2. source class `[H]|[T]|[E]|[M]`
3. legal/license basis in the body (SPDX MIT for this tree)
4. OWNER decision (`DEC-YYYY-NNNN`, status DECIDED or CLOSED)
5. S11 clean
6. PUBLIC CANDIDATE block if the artefact is a contract

CTA allowed in White Surface copy: review the public contract, run the synthetic fixture, read the telemetry boundary.

CTA forbidden: SDK seat, medical product, production API, scoring demo.
